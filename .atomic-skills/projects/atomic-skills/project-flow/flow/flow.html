Fluxo operacional · 3 camadas

Carimbar o fluxo antes de executar o plano

O operador carimba o fluxo operacional de um plano; sem o carimbo, a execução recusa.

Ator: Operador Plano: project-flow
Sequência Fluxo BPM Máquinas

Sequência

Conversa (messages) entre atores. Pode narrar interface.

  1. Operador → Agente

    Pede project flow no plano

  2. Agente → Agente

    Lê o desenho, a fonte e o intent de negócio — não a lista de fases

  3. Agente → Atomic Skills

    Grava flow.json sem carimbo

  4. Atomic Skills → Atomic Skills

    Gera flow.html com conversa, processo e estados

  5. Atomic Skills → Atomic Skills

    Roda o detector em modo estrito no arquivo do plano

  6. Agente → Operador

    Abre o painel HTML e resume o grafo no terminal

  7. Agente → Operador

    Pergunta se aprova, ajusta ou cancela — chat ok não conta

  8. Operador → Atomic Skills

    Pede implement no plano

  9. Atomic Skills → Atomic Skills

    O detector em modo estrito passa; a execução começa

  10. Atomic Skills → Operador

    Recusa. process.yaml não vale. Rode project flow e carimbe.

  11. Atomic Skills → Atomic Skills

    Só o carimbo oficial grava a data e o hash do documento

  12. Atomic Skills → Operador

    Confirma o fluxo carimbado

  13. Operador → Agente

    Diz o que está errado no grafo, nas mensagens ou nas máquinas

  14. Agente → Atomic Skills

    Reescreve flow.json e regenera o painel — sem editor visual

  1. ausente → nao_aplica Pedido sem arquivo de plano
  2. ausente → rascunho Drafta o grafo
    • write Grava o rascunho do grafo flow.json
    • write Gera o painel flow.html
  3. obsoleto → rascunho Redesenha depois que o grafo mudou
    • write Atualiza o rascunho flow.json
  4. rascunho → mostrado Mostra as três camadas
    • notify Mostra o painel ao operador Op
  5. mostrado → carimbado Operador aprova
    • write Grava data e hash do documento flow.json
  6. mostrado → rascunho Operador pede ajuste
    • write Reescreve o grafo flow.json
  7. mostrado → cancelado Operador cancela
    • notify Ready continua legal; execução não Op
  8. carimbado → em_execucao Detector libera a execução
  9. ausente → recusado Execução sem artefato
    • notify Recusa e manda carimbar no comando Op
  10. obsoleto → recusado Execução com grafo mudado
    • notify Recusa até recarimbar Op
  11. carimbado → obsoleto Grafo mudou depois do carimbo
    • other Hash do carimbo deixa de bater ratifiedGraphSha
