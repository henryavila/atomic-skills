# Canonical Antigravity (agy) Invocation (external sealed-envelope reviewer)
#
# Proven against: agy 1.2.12
# Re-smoke flags after CLI upgrades.

Use this exact command shape for every Antigravity external-review invocation.
Departure from this shape risks interactive hangs, write-capable tools, intent
framing, or stdout contamination.

## Variables to substitute

- `<BRIEFING_PATH>`: path to briefing markdown file (input)
- `<OUTPUT_PATH>`: path to output markdown file (stdout redirect)
- `<STDERR_PATH>`: path to stderr log (must live under a private `mktemp -d` dir)
- `<TIMEOUT_SECONDS>`: integer seconds (default 600 = 10 min)
- `<MODEL_FLAG>` / `REVIEW_MODEL_ID`: from Step 0.model. Default for code review is
  hybrid (Pass 1: gemini-3.8-flash-high, Pass 2: gemini-3.1-pro-high). Explicit
  flag binds `${REVIEW_MODEL_ID:+--model "$REVIEW_MODEL_ID"}`.
  Never invent an id; never pass an id that failed `isSafeReviewModelId`.

## Pre-step: private work directory (symlink-safe)

Never write stderr/output to a predictable shared `/tmp/…-<ts>` path. Create a
private dir first:

```bash
umask 077
REVIEW_TMP=$(mktemp -d "${TMPDIR:-/tmp}/as-agy-review.XXXXXX") || exit 1
trap 'rm -rf "$REVIEW_TMP"' EXIT
# Bind: <OUTPUT_PATH>=$REVIEW_TMP/out.md  <STDERR_PATH>=$REVIEW_TMP/stderr.log
#        <BRIEFING_PATH> may stay outside if already sealed by the caller
```

## Pre-step: portable timeout wrapper

```bash
if command -v timeout >/dev/null 2>&1; then
  run_with_timeout() { timeout "$@"; }
elif command -v gtimeout >/dev/null 2>&1; then
  run_with_timeout() { gtimeout "$@"; }
elif command -v perl >/dev/null 2>&1; then
  run_with_timeout() { perl -e 'alarm shift @ARGV; exec @ARGV' -- "$@"; }
else
  echo "ERROR: no timeout wrapper available. Install coreutils or perl." >&2
  exit 1
fi
```

## Command

```bash
# REVIEW_MODEL_ID must be empty or pass isSafeReviewModelId (slug-shaped).
# Briefing channel: prompt argument via -p "$(cat <BRIEFING_PATH>)"
run_with_timeout <TIMEOUT_SECONDS> agy \
  -p "$(cat <BRIEFING_PATH>)" \
  ${REVIEW_MODEL_ID:+--model "$REVIEW_MODEL_ID"} \
  --effort high \
  --sandbox \
  --disable-slash-commands \
  --output-format text \
  > <OUTPUT_PATH> 2> <STDERR_PATH>
```

## Flag-by-flag rationale

| Flag | Why |
|------|-----|
| `run_with_timeout <N>` | External kill. Portable across Linux/macOS/WSL. |
| `-p "$(cat <BRIEFING_PATH>)"` | Headless one-shot execution. Injects sealed briefing without interactive TUI. |
| `--effort high` | High reasoning effort for adversarial review (flash models do not support max). |
| `--sandbox` | Run in sandbox with terminal restrictions enabled. Reviewer must not mutate workspace. |
| `--disable-slash-commands` | Skills and slash commands must not inject framing or trigger unwanted flows. |
| `--output-format text` | Clean markdown response on stdout without TUI or ANSI escapes. |
| `> <OUTPUT_PATH>` | Persist response for Pass validation. |
| `2> <STDERR_PATH>` | Keep spinners and logs out of the review file. |

## DO NOT

- DO NOT omit `--disable-slash-commands` — skills could inject framing.
- DO NOT use `--mode accept-edits` — reviewer must be read-only.
- DO NOT use `--effort max` — incompatible with Gemini Flash models.
- DO NOT resume conversations (`-c` / `--continue` / `--conversation`) across passes.
