1. Fluxo principal + ponto de decisão

Atenção: esta página é legada / não canônica — caminhos lineares sem as 3 decisões XOR do modelo. Fonte de verdade: fluxo completo + fluxo-sugestao.json (validação do envio, edição, aceite/recusa; status 10 → 1 / 11). Abaixo: blocos no formato Parte A (barra + sequência linear), sem caixas opt/alt.

Parte A · Até o líder ver a sugestão Caminho feliz da criação até a tela · GETIN → Sistema → Líder
Parte B · Se o líder aceitar Continua da tela da sugestão · inclui edição se houver · depois entra no funil
Parte B · Se o líder recusar Continua da tela da sugestão · inclui edição se houver · encerra e avisa a GETIN
Parte C · Se der erro ao criar (fluxo separado) Só na criação · não envia e-mail até o envio ser válido

2. Quem faz o quê em cada etapa
